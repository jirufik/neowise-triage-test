# О проекте: AI-помощник для входящих заявок (тестовое Neowise)

> **Коротко.** Менеджер вставляет текст заявки клиента и нажимает «Разобрать». Сервер спрашивает модель (здесь — имитатор) и показывает тему заявки и черновик ответа; что отправить клиенту, решает менеджер. В выданном коде любой сбой ломает работу: пустой текст, зависшая модель или странный ответ модели дают ошибку 500 или мусор на экране. Задача — чтобы сбой модели никогда не выглядел как готовый ответ: менеджер видит «разберите вручную», а старый черновик пропадает с экрана.
>
> **Что решить вам:** где публиковать репозиторий для PR (см. ТЗ, раздел «Решения»).

## Слова

- **Заявка** — текст от клиента, который вставляет менеджер.
- **Тема** — одна из трёх: `delivery` (доставка), `pricing` (цены), `other` (другое).
- **Черновик** — предложенный текст ответа клиенту.
- **Ручной разбор** (`manual_review`) — модель не дала годного результата; менеджер разбирает заявку сам.
- **Имитатор** — `mock-ai.mjs`, заменяет настоящую модель; метки в тексте (`[timeout]`, `[error]`, `[bad-json]`, `[bad-topic]`, `[empty-draft]`) включают сбои.

## Что в выданном коде (как было)

| Файл | Что делает | Что не так |
|---|---|---|
| `server.mjs` | HTTP-сервер: `GET /` — страница, `POST /api/triage` — разбор | битый JSON и пустой текст → 500; ответ модели не проверяется — `[bad-topic]`, `[empty-draft]` уходят как `ready`; `[bad-json]`, `[error]` → 500; `[timeout]` ждёт 1,2 с |
| `mock-ai.mjs` | имитатор модели, принимает `signal` для отмены | менять нельзя по условию |
| `index.html` | форма и вывод сырого JSON | менеджер видит JSON; при ошибке старый результат остаётся; ответы двух быстрых запросов могут прийти в обратном порядке |

## Как устроено после доработки

```
Менеджер → index.html → POST /api/triage → проверка ввода → модель (≤ 300 мс) → проверка ответа модели → ready | manual_review
                                             └─ 400 invalid_input
```

- Проверка ввода и ответа модели — в `triage.mjs` (чистые функции, тестируются без сети).
- Сервер — `app.mjs` (обработчик, модель подставляется в тестах), запуск — `server.mjs`.
- Отображение — `ui.mjs` (чистая функция «ответ API → что показать» и защита от запоздавшего ответа), подключается страницей.
