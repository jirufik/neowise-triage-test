## Находки

1. Защитная проверка темы в `viewFor` (`ui.mjs`) через `in` видит унаследованные свойства (`toString`, `__proto__`). Сервер такую тему не отдаст, но клиентская защита дырявая. Исправление: `Object.hasOwn` и тест.
2. Требование «прежний результат стирается сразу, до ответа» не проверяется: удаление `render(pendingView())` не ловится e2e. Исправление: e2e, где после успеха отправляется `[timeout]` и `#draft` пуст раньше 300 мс.
3. Защиту от запоздавшего ответа дублируют две меры (отмена прежнего запроса и проверка билета); удаление одной e2e не замечает. Поведение верное.
4. В `callModel` строка `call.catch(() => {})` лишняя — `Promise.race` уже вешает обработчик; комментарий вводит в заблуждение. `clearTimeout` — страховка, без неё утечки по сути нет.
5. Противоречия в `docs/TZ.md` («Вне объёма: e2e» при наличии e2e; «одной командой `npm test`»); внутренние пометки в публичных документах.
6. Неотслеживаемый `docs/PR.md` — решить: закоммитить или удалить.
7. Мелочи: тело с BOM даёт 400 (как `JSON.parse`); порт e2e 3123 переопределяется `E2E_PORT`, в README не упомянуто.
