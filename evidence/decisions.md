# Решения, вынесенные автору

## Где публиковать PR (вынесено 23.11, до публикации)

| Вариант | Плюсы | Минусы |
|---|---|---|
| **А. Публичный репозиторий на GitHub автора** | проверяющий открывает ссылку без доступа; условие прямо допускает учебный репозиторий; в коде нет личных данных, данные учебные | репозиторий виден всем |
| Б. Приватный репозиторий | посторонние не видят | нужен ник проверяющего на GitHub — его нет; бот, скорее всего, не откроет ссылку |
| В. Архивом | ничего не публикуется | нарушает условие «ссылка на pull request» |

Рекомендация — **А**. Решение автора: А (условие требует ссылку вида `https://github.com/owner/repo/pull/1`).

Первоначальная запись — в ТЗ промежуточного коммита `22e8b19`, раздел «Решения» (`git show 22e8b19:docs/TZ.md`).
